## What Was Done

### Bug Fixes

**1. Admin dashboard infinite skeleton (`admin/page.tsx`)**
- Root cause: `useEffect` had an empty `[]` dependency array but used `tmsUser?.courseId` inside.
  On first mount, `tmsUser` is null (Firebase auth still loading), the guard fired, and the effect never re-ran.
- Fix: changed dependency array from `[]` to `[tmsUser]`.

**2. All admin + tech-admin pages hang on infinite skeleton when `courseId`/`schoolId` is missing**
- Root cause: guards like `if (!tmsUser?.courseId) return;` never called `setLoading(false)`, so
  pages with a correctly set `[tmsUser]` dependency would still hang if the Firestore user doc
  was missing `courseId` or `schoolId` (e.g. pre-migration accounts).
- Fix: added explicit `setLoading(false)` before early return in the null-field case across all 8 pages:
  - `admin/page.tsx`, `admin/users/page.tsx`, `admin/theses/page.tsx`, `admin/assign/page.tsx`, `admin/schedules/page.tsx`
  - `tech-admin/page.tsx`, `tech-admin/courses/page.tsx`, `tech-admin/users/page.tsx`

**3. Admin dashboard warning instead of silent blank**
- When coordinator has no `courseId`, the dashboard now renders a yellow warning card:
  "Your account is not linked to a course yet. Ask your Tech Admin to assign you as coordinator."

### New Feature

**4. Tech Admin dashboard — school name heading**

- Renders the school name as a `text-4xl font-bold` heading above the "Tech Admin Dashboard" subheading.
- Shows a skeleton placeholder while loading; falls back to `"Your School"` if the doc is missing.

## How to Add a New School

Schools are created manually by the developer (no UI — intentional, each school is a separate tenant):

1. Firebase console → Firestore → `schools/` → Add document
   - `name` (string): school name
   - `createdAt` (timestamp): now
2. Register any user account → Firestore → `users/{uid}`:
   - `role: "tech_admin"`
   - `schoolId: "<schools doc ID from step 1>"`
   - `courseId: null`
3. Log out and back in → routed to `/tech-admin`
4. Tech admin adds courses and assigns coordinators via the UI
